🤖 Wbrowser

A dedicated profile, kept separate from your everyday Chrome. Bookmarks, extensions and logins never mix.

1
Sign in to your accounts here. Gmail or anywhere else — once you log in, the session stays in this profile and the agent picks up from that state next time. If Chrome asks "Save password?", go ahead — only Chrome keeps it, and the agent can't see the value.
i
Why this window and not your usual Chrome — since Chrome 136 the default profile blocks external control (a defence against cookie-theft attacks). That makes a dedicated profile the only way in. Just build your logins up here.
2
Leave this window open. If you close it, the agent has nothing left to drive. Minimising is fine.
3
For the rest, just ask in plain words. No terminal commands to memorise — say something like "clear out the unread mail in here" and the agent will drive this window for you.
🔴 The agent will not type passwords for you. That's forbidden by policy. Sign in yourself in this window; the agent only reuses the session afterwards.
